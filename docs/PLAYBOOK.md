# 建站手册（从 dshtoolbox.com 上归纳）

这份东西来自一个真实站点：从零到 220 条 URL、进 GSC 第三周、拿到 981 次展示和 20 次点击。样本不大，所以下面只写**已经有证据**的，以及**踩过就不要再踩**的。

## 一、先判断站在哪个阶段

| 阶段 | 证据 | 只做这些 |
| --- | --- | --- |
| 没有收录 | GSC 里没有页面 | 提交索引、内链、少量内页 |
| 有曝光无排名 | 曝光有、平均排名 20 名外 | 改标题与首屏，别加页面 |
| 有排名无点击 | 进前 20、CTR 低于 2%、展示 ≥ 50 | 先看查询词对不对，再动标题 |
| 有点击无转化 | 有流量、跳出高 | 场景化文案、砍掉无关段落 |
| 有订单 | 有转化 | 复制到相近场景，慎改结构 |

**展示低于 10 次的页面不参与判断。** 那是个位数噪声，不是信号。真站上出现过 7 条「排名 20 名外、零点击」，全部只有 1–6 次展示，改了等于白改。

## 二、页面只有四种，别发明第五种

1. **工具页**：一个页面解决一件具体的事，输入输出都在浏览器里。转化最好，也最容易被引用。
2. **报错页**：报错原文当标题，原因、命令、复验。真站上唯一有点击的集群就是这一类。
3. **对比页**：A vs B，读者带着选择来的，长尾多。
4. **目录页**：把同类东西列全。它的价值是内链，不是流量。

博客是补充，不是主力。纯文字页在工具站上排不动，也不好过广告审核。

## 三、内页要慢，用收录当闸门

新站一次加十个页面，收录失败时你分不清是页面问题还是站点问题。

1. 提交 GSC，等首页收录
2. 加第 1 个内页 → 等被收录 → 成功才加第 2 个
3. 第 2 个成功 → 可以加速，但每批都回头看收录率
4. 收录率连续低 → 停手，查模板重复与内链

## 四、薄页要合并，不要硬撑

真站上 10 个官方能力包各有一页，模板相同、内容雷同、大多没被收录。合并成一页并 301 之后：

- URL 从 236 降到 218
- 内容密度上去，单页有了真正的差异（版本、发布日期、体积、下载量）
- 旧地址 301，权重不至于全丢

判据：**同一模板下、差异只有两三句、且抓取后长期不收录** → 合并。

合并时必须做三件事：旧地址 301、旧 URL 从 sitemap 去掉、新页从目录页收内链。

## 五、可嵌入是最便宜的外链

买链、博客评论、目录提交，投入产出都差。工具站能做的是：给每个工具一个 `?embed=1` 模式，页面上直接给 iframe 代码。

这一步最容易漏的是响应头：

```
Content-Security-Policy: frame-ancestors 'self' https:
```

有 `X-Frame-Options: SAMEORIGIN` 在，别人嵌进来就是白屏，而且本地看不出来——必须上线后用另一个域名验证一次。

## 六、截图要真，位置要显眼

- 2x 截图，按元素边界裁剪，只含工具本体，不带导航和标题
- 放页面第一屏，正文说明之前
- 中英各一套，`zh-` 前缀
- 截图模式用 `?shot=1` 在页面里摘壳，不要在截图脚本里删 DOM

系统 Chrome 的 `--headless --screenshot` 在一台机器上可以连续五次返回同一张图，不是缓存，是它没渲染。用 Playwright 自带的 Chromium。

## 七、数据口径别混

| 工具 | 能回答 | 不能回答 |
| --- | --- | --- |
| Google Trends | 走势、地域、相对热度 | 「这个词每月多少搜索」 |
| Similarweb | 量级、来源结构 | 某一页的准确流量 |
| GSC 查询 | 真实搜索词、点击、排名 | 竞品 |
| GSC 网页 | 页面级曝光与点击 | 词与页的对应关系 |
| 关键词工具 | 搜索量区间、竞争度 | 趋势 |

跨工具比趋势可以，比绝对值不行。

## 八、已知的坑

- **包名被占**：发布前先查 registry，别等构建完才发现重名
- **改名只改了一半**：包名、bundle id、加载器条目、站点路径、仓库地址、数据目录，六个地方少一个就有一半不工作
- **本地凭据用完就删**：删掉的代价是下次重做一遍登录。放 `~/.dsh/.credentials.yaml`，默认不删
- **从截图里抄密钥**：字符会认错，401 排查半天。密钥只从文件或环境变量读
- **首页数量文案与卡片数不一致**：改完卡片刻意数一遍，验收脚本里把数字写死
- **X-Frame-Options**：嵌入白屏的第一嫌疑
- **单源调研**：只搜一个搜索引擎、只看一份 AI 报告，就敢定赛道。竞品必须人工点进去看过

## 九、什么时候停

出现两条就该换赛道，而不是「再优化一下」：

1. 赛道头部站点的流量上限本身很低
2. 关键词整体趋势在下滑
3. 内容形态单薄，变现路径走不通

三个月没有曝光增长，是赛道问题，不是执行问题。
