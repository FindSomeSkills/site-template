# 发布检查单

每一条都对应一次真实事故，不是形式。

- [ ] `npm run verify` 全过（构建、title/description、本机路径、字面量转义、英文页中文、sitemap 条数、六组渲染）
- [ ] 有界面的工具放了**真实截图**，在页面第一屏，只含工具本体，2x，中英各一张
- [ ] 首页有卡片指向新页面，数量文案与实际卡片数一致
- [ ] 旧地址都写了 301，旧 URL 已从 sitemap 消失
- [ ] `public/_headers` 里的 `frame-ancestors` 还在（删了整个站的 iframe 嵌入都会白屏）
- [ ] 部署后逐页比对线上与本地哈希，两张图各取一次 200
- [ ] GSC 提交新 URL；sitemap 条数与构建一致
- [ ] 记一笔：地址、日期、版本、待办

## 不要做

- 不要因为个位数展示改标题
- 不要一次改十条
- 不要用新增页面去对冲收录慢
- 不要在共享目录里直接改
